## Timeline
- Start work as soon as the topic is approved (pre-approved topics: right
  after filling the selection form; custom proposals: after instructor
  approval).
- Project must be completed within one term — **final deadline 20
  September**. Final submission = report + video demo + code.

## Evaluation weights
| Component              | Weight |
|-------------------------|--------|
| Report                  | 10%    |
| Own Project Proposal    | 5% (bonus, only for self-proposed topics) |
| Video Demo               | 15%    |
| Presentation             | 20%    |
| Viva                     | 50%    |

- Viva: first attempt max 50%; make-up attempt capped at 40% (automatic
  10% deduction) — prepare thoroughly for the first attempt.
- Plagiarism is checked; large gaps between report quality and viva/demo
  performance can be referred to the Disciplinary and Welfare Committee.
- Submit via the Seek portal.

## Report format (required sections)
1. Abstract
2. Introduction
3. Problem statement
4. Goals and Objectives
5. Methodology
6. Implementation details
7. Problems faced during implementation and their solutions
8. Results and discussions
9. Conclusions
10. Contribution of the individual (for group projects)
11. Annexure — Google Drive link with video demo + code zip. **Access must
    be "anyone with the link" or the components tied to it score zero.**

## Software/hardware policy
- Software-based project is the default (course is remote-mode).
- Hardware-based project needs on-campus time + faculty approval.
- Allowed languages: MATLAB, Python, C/C++, Java, Verilog/VHDL,
  HTML/CSS/JS, LabVIEW.

## Topic approval
- Pick from the pre-approved list (SP01–SP25) or propose a custom topic.
- Custom proposal must cover: Problem, Objectives, Methodology — reviewed
  by the instructor before work begins.
- Proposal email: to `vishal@study.iitm.ac.in`, cc
  `venkatesan@study.iitm.ac.in`, `ankita_p@study.iitm.ac.in`.

## Group projects
- Allowed; scope must be proportionally larger.
- Even in a group, each person submits their own report and is evaluated
  individually.
